# Print Method for Generated SQL

Echoes the generated SQL verbatim instead of the quoted, escaped form
base R would print for a character vector.

## Usage

``` r
# S3 method for class 'obwoe_sql'
print(x, ...)
```

## Arguments

- x:

  An object of class `"obwoe_sql"`.

- ...:

  Additional arguments (currently ignored).

## Value

Invisibly returns `x`.

## See also

[`obwoe_sql`](https://evandeilton.github.io/OptimalBinningWoE/reference/obwoe_sql.md)

## Examples

``` r
# \donttest{
set.seed(1)
df <- data.frame(x = rnorm(500))
df$target <- rbinom(500, 1, plogis(df$x))
print(obwoe_sql(obwoe(df, target = "target"), table = "t"))
```
